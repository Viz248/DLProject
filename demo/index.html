Is the model drifting?

The full monitoring system replayed on the 8,117-step Elec2 test stream. Pick a scenario: we inject drift of a known type and size at step 4,000, the MLP keeps predicting and learning online, and five methods watch it: the existing detectors ADWIN, DDM and CUSUM, and our RiskGate-CUSUM and LSTM forecaster. The verdict compares the 2,000 steps before the injection with the 2,000 after.

How the verdict is decided

Regenerate with python -m src.demo after python -m src.train. One scenario in the terminal: python -m src.demo --scenario sudden --severity 0.25.

Error-rate confidence intervals use a moving-block bootstrap (blocks of 50 steps) because errors arrive in bursts. "No drift" means no evidence of drift in this window, not proof that nothing changed.
